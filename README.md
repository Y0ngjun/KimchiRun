# Kimchi Run
Unity로 제작한 2D 러너 게임입니다.

## 게임의 특징
- 배달 오토바이, 할머니, 비둘기를 피하세요
- 김장 재료를 얻어 체력을 회복하세요
- 황금 배추를 얻어 무적효과를 사용하세요
